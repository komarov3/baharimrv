## High-level view

The CSS class token fix is complete: `.mw-btn--g` in `styles.css` and all four JSX call sites now use the correct BEM modifier. Green buttons in the web frontend will render as intended.

The cross-role cap issuance race at login is closed. `IssueCapForUser` was previously dispatched as a nested goroutine inside the outer background goroutine for hub-resolved role upgrades; the fix commit removes the inner `go`, so cap issuance runs synchronously within the outer goroutine and the write no longer races itself.

The Gazi Bay seed torn-state gap is resolved. `runGaziBay` now queries for the Hamisi manager account by email before calling `account()`: if the account exists it is reloaded; if not, it is created. Either way the function continues to project creation, so a partially applied seed resumes correctly rather than returning early.

The `google-services.json` CI requirement is documented in `BAHARILINK_SETUP.md` with the exact path, the Firebase console project name, and an explicit note that CI/CD must inject the file as a secret before the Gradle build step.
